
# TithiMitra

A Marathi-first Panchang and Vrat reminder application.

TithiMitra is being built to help users track important Hindu observances, view location-specific lunar timings, and receive reminders for relevant rituals.

## Planned Features

- Purnima and Amavasya tracking
- Ekadashi and Sankashti Chaturthi tracking
- Angarki Sankashti observances
- Tithi start and end timings
- Location-specific moonrise and moonset
- Configurable ritual reminders
- English interface with Marathi event names
- City selection for locations across Maharashtra

## Technology Stack

- React Native with Expo
- Supabase and PostgreSQL
- Python
- FastAPI

## Current Status

The project is in its initial development stage.

The first web interface is under development. Panchang data integration, event validation, and notification functionality have not yet been implemented.

**Important:** The current interface contains placeholder timings. It must not be used to determine actual fasting or ritual timings.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

Press `w` in the terminal to open the web application.

## Project Goals

Build a reliable, location-aware Panchang companion with clearly documented calculation methods, validated observance dates, and useful notifications.
